# Getting started

## Mac

1. Open `TimeKeeper.xcodeproj` in Xcode.
2. Choose **My Mac** → Run.
3. Optional: copy the built app to `/Applications` for double-click launch.

## iPhone Simulator

1. Same project; pick an iPhone Simulator destination → Run.
2. Bundle ID: `app.timekeeper`.

## Physical iPhone

1. Connect the phone, trust the computer.
2. In Xcode → Signing & Capabilities, select your Team (Apple ID).
3. Run to the device.

Paid Apple Developer Program is only required for TestFlight / App Store / some device profiles — not for Simulator work.
